# Starsync

Watch videos with friends, in sync, in a real mpv player. Put up any video and
everyone watches it together: the relay reads it once and passes it to the
whole group, so nobody needs their own copy of the file.

**Website, screenshots and how it works:** https://foxyz.ru/apps/starsync/

## Download

Get the latest build from [Releases](https://github.com/Foxyz1302/starsync/releases/latest):

- Windows: `starsync-<version>-windows-x64.zip` (mpv is included)
- Linux: `starsync-<version>-linux-x64.tar.gz` (needs mpv's library: the `mpv` or `libmpv2` package)

Changes in every version: [CHANGELOG.md](CHANGELOG.md).

This repository only hosts the release builds.
